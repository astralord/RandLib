# Legacy mathematical notes

`document.tex` and `images/` are archival source material and may contain obsolete API,
implementation, or accuracy statements. Use the
[current mathematical reference](../reference/index.md) for supported behavior.

Build from this directory with a suitably complete LaTeX installation:

```sh
pdflatex document.tex
pdflatex document.tex
```

The generated PDF is intentionally not versioned. Current API documentation is generated from the
public headers with Doxygen.
